# PRF ADM 2026 — Landing Page

Landing page do aplicativo **PRF ADM: Questões, Simulados e Quiz** para concurso de Agente Administrativo da Polícia Rodoviária Federal (nível médio).

## Seções

- **Hero** — Apresentação do app com links para a Google Play e planos
- **Como Funciona** — Banco de questões por disciplina, revisão inteligente e simulado cronometrado
- **Metodologia** — Explicações pedagógicas e simulação de pressão real de prova
- **Offline** — Banco de dados SQLite integrado, funciona sem internet
- **Planos** — Anual (R$ 19,99) e Vitalício (R$ 34,99), pagamento único
- **Carrossel** — Galeria de telas do aplicativo
- **FAQ** — Perguntas frequentes sobre justificativas, atualizações, modo offline, simulados e planos

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, flexbox, grid, gradientes)
- JavaScript vanilla (carrossel com autoplay)

## Como usar

Abra o `index.html` no navegador ou sirva com um servidor local:

```bash
npx serve .
```
